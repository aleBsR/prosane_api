Guardar antecedentes familiares

PUT /api/v1/<id>/antecedentes-familiares/ Requiere: Autenticación

Descripción

Crea o actualiza los antecedentes familiares de un paciente (upsert). Si no existen, se crean; si existen, se actualizan parcialmente.

Request Body

{
  "problemas_salud": "SI",
  "detalle_problema_salud": "Diabetes tipo 2 en abuelos",
  "familiar_con_muerte_subita": "NO"
}

Response — 200 OK (actualizado) o 201 Created (nuevo)

{
  "problemas_salud": "SI",
  "detalle_problema_salud": "Diabetes tipo 2 en abuelos",
  "familiar_con_muerte_subita": "NO"
}

Campos del request

CampoTipoRequeridoDescripción
problemas_saludstringNo"SI" o "NO"
detalle_problema_saludstringNoDetalle de problemas de salud familiares
familiar_con_muerte_subitastringNo"SI" o "NO"

Ejemplo con curl

curl -X PUT http://localhost:8000/api/v1/1/antecedentes-familiares/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "problemas_salud": "SI",
    "detalle_problema_salud": "Diabetes",
    "familiar_con_muerte_subita": "NO"
  }'
