Registro de tutor

POST /auth/register-tutor/ Público

Descripción

Registra un usuario con rol tutor y crea automáticamente su perfil de Responsable (responsable a cargo de pacientes menores).

Request Body

{
  "usuario": {
    "email": "tutor@ejemplo.com",
    "password": "contraseña123",
    "persona": {
      "nombre": "María",
      "apellido": "García",
      "dni": "87654321",
      "tipo_dni": "DNI",
      "sexo": "F",
      "fecha_nacimiento": "1985-03-20"
    }
  },
  "parentesco": "madre"
}

Response — 201 Created

{
  "message": "Tutor created succesfully"
}

Campos del request

CampoTipoRequeridoDescripción
usuario.emailstringSíEmail del tutor
usuario.passwordstringSíContraseña
usuario.persona.*objectVaríaDatos de la persona (ver register)
parentescostringSíEj: "madre", "padre", "tutor", "abuelo"
