Inicio de sesión

POST /auth/login/ Público

Descripción

Inicia sesión con email y contraseña. Devuelve un JWT que incluye los roles del usuario en el payload.

Request Body

{
  "email": "usuario@ejemplo.com",
  "password": "contraseña123"
}

Response — 200 OK

{
  "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9..."
}

El token contiene los roles en el payload. Podés decodificarlo (ej: con jwt.io) y verás algo como:

{
  "token_type": "access",
  "exp": 1717000000,
  "iat": 1716996400,
  "user_id": "uuid-del-usuario",
  "roles": [
    {"rol": "tutor", "ruta": null}
  ]
}

Ejemplo con curl

curl -X POST http://localhost:8000/auth/login/ \
  -H "Content-Type: application/json" \
  -d '{
    "email": "tutor@ejemplo.com",
    "password": "contraseña123"
  }'
