Perfil del profesional

GET /api/v1/profesionales/perfil/ Requiere: Autenticación

Descripción

Obtiene el perfil completo del profesional autenticado: datos de usuario, persona y matrícula.

Response — 200 OK

{
  "email": "medico@ejemplo.com",
  "persona": {
    "id": 5,
    "nombre": "Estela Rosa",
    "apellido": "Acevedo",
    "dni": "12497922",
    "tipo_dni": "DNI",
    "sexo": "female",
    "fecha_nacimiento": "1956-10-18"
  },
  "profesional": {
    "id": 1,
    "matricula": "541012497922"
  }
}

Response — 404 Not Found

{
  "detail": "No se encontró un perfil profesional para este usuario."
}

Ejemplo con curl

curl -X GET http://localhost:8000/api/v1/profesionales/perfil/ \
  -H "Authorization: Bearer <token>"
