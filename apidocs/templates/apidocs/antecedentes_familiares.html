Obtener antecedentes familiares

GET /api/v1/<id>/antecedentes-familiares/ Requiere: Autenticación

Descripción

Obtiene los antecedentes familiares de un paciente específico.

Response — 200 OK

{
  "problemas_salud": "NO",
  "detalle_problema_salud": "",
  "familiar_con_muerte_subita": "NO"
}

Response — 404 Not Found

{
  "detail": "No se encontraron antecedentes familiares para este paciente."
}

Ejemplo con curl

curl -X GET http://localhost:8000/api/v1/1/antecedentes-familiares/ \
  -H "Authorization: Bearer <token>"
