Crear paciente

POST /api/v1/ Requiere: Autenticación

Descripción

Crea un nuevo paciente con sus datos personales y domicilio. Si el usuario autenticado es un tutor, el responsable se asigna automáticamente.

Request Body

{
  "persona": {
    "nombre": "Lucía",
    "apellido": "García",
    "dni": "12345678",
    "tipo_dni": "DNI",
    "sexo": "F",
    "fecha_nacimiento": "2015-06-10"
  },
  "domicilio": {
    "calle": "Av. Ejemplo",
    "nro_calle": "1234",
    "piso": "",
    "dpto": "",
    "provincia": "Salta",
    "departamento": "Capital",
    "localidad": "Salta"
  },
  "edad": 10,
  "tiene_cud": "NO",
  "tipo_cobertura": "PUBLICA",
  "nombre_cobertura": ""
}

Response — 201 Created

{
  "id": 1,
  "persona": { ... },
  "domicilio": { ... },
  "responsable": 1,
  "edad": 10,
  "tiene_cud": "NO",
  "tipo_cobertura": "PUBLICA",
  "nombre_cobertura": "",
  "responsable_detalle": { ... }
}

Campos del request

CampoTipoRequeridoDescripción
persona.*objectSíDatos personales del paciente
domicilio.*objectSíDomicilio del paciente
edadintegerSíEdad del paciente
tiene_cudstringNo"SI" o "NO" (CUD = Certificado Único de Discapacidad)
tipo_coberturastringNo"PUBLICA", "PRIVADA" u "OBRA_SOCIAL"
nombre_coberturastringNoNombre de la cobertura médica
responsableintegerNo*ID del responsable. Se asigna automáticamente si el usuario autenticado es tutor
