Registro de usuario

POST /auth/register/ Público

Descripción

Registra un nuevo usuario genérico en el sistema. Crea una Persona y un Usuario asociado. Por defecto asigna el rol usuario.

Request Body

{
  "email": "usuario@ejemplo.com",
  "password": "contraseña123",
  "persona": {
    "nombre": "Juan",
    "apellido": "Pérez",
    "dni": "12345678",
    "tipo_dni": "DNI",
    "sexo": "M",
    "fecha_nacimiento": "2010-05-15"
  }
}

Response — 201 Created

{
  "message": "User created succesfully",
  "data": {
    "id": "uuid-del-usuario",
    "email": "usuario@ejemplo.com",
    "persona": {
      "nombre": "Juan",
      "apellido": "Pérez",
      "dni": "12345678",
      "tipo_dni": "DNI",
      "sexo": "M",
      "fecha_nacimiento": "2010-05-15"
    }
  }
}
