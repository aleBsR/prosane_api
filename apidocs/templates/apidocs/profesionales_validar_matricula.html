Validar matrícula profesional

POST /api/v1/profesionales/validar-matricula/ Requiere: Autenticación

Descripción

Valida una matrícula profesional contra el sistema REFEPS. Útil para verificar la identidad de un profesional antes de registrarlo o para consultas administrativas.

Request Body

{
  "matricula": "541012497922"
}

Response — 200 OK

{
  "nombre": "Estela Rosa",
  "apellido": "Acevedo",
  "dni": "12497922",
  "sexo": "female",
  "fecha_nacimiento": "1956-10-18",
  "profesion": "Médico"
}

Response — 400 Bad Request

{
  "error": {
    "matricula": ["Matrícula no válida o no encontrada"]
  }
}

Matrículas de prueba (modo mock)

MatrículaProfesiónTitular
541012497922MédicoEstela Rosa Acevedo
123456789OdontólogoCarlos López

Nota: Actualmente REFEPS opera en modo mock (REFEPS_MOCK = True). Solo las matrículas de prueba funcionan. Cuando se integre con REFEPS real, cualquier matrícula válida será aceptada.

Ejemplo con curl

curl -X POST http://localhost:8000/api/v1/profesionales/validar-matricula/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"matricula": "541012497922"}'
