Registro de profesional

POST /auth/register-profesional/ Público

Descripción

Registra un profesional de la salud (médico u odontólogo). Valida la matrícula contra REFEPS y asigna el rol correspondiente automáticamente. Los datos personales se obtienen desde REFEPS.

Request Body

{
  "email": "medico@ejemplo.com",
  "password": "contraseña123",
  "matricula": "MAT-12345"
}

Response — 201 Created

{
  "message": "Professional created succesfully"
}

Campos del request

CampoTipoRequeridoDescripción
emailstringSíEmail del profesional
passwordstringSíContraseña
matriculastringSíNúmero de matrícula profesional (validado contra REFEPS)

Nota: Actualmente REFEPS opera en modo mock (REFEPS_MOCK = True). La validación real estará disponible cuando se integre con el servicio de REFEPS.
