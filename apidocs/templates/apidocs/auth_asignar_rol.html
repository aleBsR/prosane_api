Asignar rol a usuario

POST /auth/rol/<id> Requiere: Admin

Descripción

Asigna un rol a un usuario existente. Solo accesible por usuarios con permisos de administrador (is_superuser).

Request Body

{
  "id_rol": "medico"
}

Response — 200 OK

{
  "message": "rol asigned",
  "data": {
    "id_rol": "medico"
  }
}

Campos del request

CampoTipoRequeridoDescripción
id_rolstringSíNombre del rol: "medico", "odontologo", "tutor", "ayudante"

Nota: El rol "admin" no se asigna por este endpoint. Se obtiene siendo is_superuser en el modelo Usuarios.
