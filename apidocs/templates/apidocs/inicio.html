PROSANE API

API REST del circuito PROSANE (Programa Nacional de Salud Escolar) en Salta Capital.

Esta API funciona como capa intermedia entre la aplicación móvil (Flutter) y los sistemas provinciales (SISA, REFEPS, RENAPER).

Endpoints disponibles

MétodoEndpointDescripción
POST/auth/register/Registro de usuario genérico
POST/auth/register-tutor/Registro de tutor con creación de responsable
POST/auth/register-profesional/Registro de profesional con validación REFEPS
POST/auth/login/Inicio de sesión (JWT)
POST/auth/rol/<id>Asignar rol a usuario (solo admin)
GET/api/v1/Listar pacientes del tutor autenticado
POST/api/v1/Crear nuevo paciente
GET/api/v1/<id>/Detalle de un paciente
PUT/api/v1/<id>/Actualizar paciente completo
PATCH/api/v1/<id>/Actualizar paciente parcialmente
DELETE/api/v1/<id>/Eliminar paciente
GET/api/v1/<id>/antecedentes-familiares/Obtener antecedentes familiares
PUT/api/v1/<id>/antecedentes-familiares/Crear o actualizar antecedentes familiares
GET/api/v1/<id>/antecedentes-personales/Obtener antecedentes personales
PUT/api/v1/<id>/antecedentes-personales/Crear o actualizar antecedentes personales
GET/api/v1/responsable/Ver perfil del tutor autenticado
PUT/api/v1/responsable/Crear o actualizar perfil del tutor

Formato general

Todos los endpoints requieren autenticación vía JWT (Bearer token), excepto los de registro y login que son públicos.

Las respuestas son en formato JSON. Los códigos de estado siguen el estándar HTTP.
