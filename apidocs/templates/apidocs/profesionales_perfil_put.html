Actualizar perfil del profesional

PUT /api/v1/profesionales/perfil/ Requiere: Autenticación

Descripción

Actualiza los datos de persona del profesional autenticado.

Request Body

{
  "persona": {
    "nombre": "Estela Rosa",
    "apellido": "Acevedo de González",
    "telefono": "387-5551234"
  }
}

Response — 200 OK

{
  "email": "medico@ejemplo.com",
  "persona": {
    "id": 5,
    "nombre": "Estela Rosa",
    "apellido": "Acevedo de González",
    "dni": "12497922",
    "tipo_dni": "DNI",
    "sexo": "female",
    "fecha_nacimiento": "1956-10-18"
  },
  "profesional": {
    "id": 1,
    "matricula": "541012497922"
  }
}

Campos del request

CampoTipoRequeridoDescripción
persona.nombrestringNoNombre del profesional
persona.apellidostringNoApellido del profesional
persona.dnistringNoDNI
persona.sexostringNoSexo registral
persona.fecha_nacimientodateNoFecha de nacimiento

Ejemplo con curl

curl -X PUT http://localhost:8000/api/v1/profesionales/perfil/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"persona": {"apellido": "Acevedo de González"}}'
