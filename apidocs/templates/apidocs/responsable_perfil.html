Ver perfil del responsable

GET /api/v1/responsable/ Requiere: Autenticación

Descripción

Obtiene el perfil del tutor/responsable asociado al usuario autenticado.

Response — 200 OK

{
  "id": 1,
  "usuario": "uuid-del-usuario",
  "persona": 5,
  "parentesco": "madre"
}

Response — 404 Not Found

{
  "detail": "No se encontró un perfil de tutor/responsable para este usuario."
}

Ejemplo con curl

curl -X GET http://localhost:8000/api/v1/responsable/ \
  -H "Authorization: Bearer <token>"
