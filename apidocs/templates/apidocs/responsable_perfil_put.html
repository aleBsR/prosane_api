Actualizar perfil del responsable

PUT /api/v1/responsable/ Requiere: Autenticación

Descripción

Crea o actualiza el perfil del tutor/responsable del usuario autenticado. Si no existe perfil, se crea uno nuevo.

Request Body

{
  "parentesco": "padre"
}

Response — 200 OK (actualizado) o 201 Created (nuevo)

{
  "id": 1,
  "usuario": "uuid-del-usuario",
  "persona": 5,
  "parentesco": "padre"
}

Campos del request

CampoTipoRequeridoDescripción
parentescostringNoParentesco con el paciente: "madre", "padre", "tutor", "abuelo", "otro"

Ejemplo con curl

curl -X PUT http://localhost:8000/api/v1/responsable/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"parentesco": "padre"}'
