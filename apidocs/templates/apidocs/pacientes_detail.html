Detalle de paciente

GET /api/v1/<id>/ Requiere: Autenticación

Descripción

Obtiene los datos completos de un paciente específico por su ID.

Response — 200 OK

{
  "id": 1,
  "persona": { ... },
  "domicilio": { ... },
  "responsable": 1,
  "edad": 10,
  "tiene_cud": "NO",
  "tipo_cobertura": "PUBLICA",
  "nombre_cobertura": "",
  "responsable_detalle": {
    "id": 1,
    "parentesco": "madre",
    "nombre": "María",
    "apellido": "García"
  }
}

Ejemplo con curl

curl -X GET http://localhost:8000/api/v1/1/ \
  -H "Authorization: Bearer <token>"

Parámetros de URL

ParámetroTipoDescripción
idintegerID del paciente
