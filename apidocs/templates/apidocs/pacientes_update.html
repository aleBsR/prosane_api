Actualizar paciente

PUT /api/v1/<id>/ Requiere: Autenticación

Descripción

Actualiza todos los datos de un paciente (reemplazo completo). También disponible como PATCH para actualización parcial.

Request Body

{
  "persona": {
    "nombre": "Lucía",
    "apellido": "García",
    "dni": "12345678",
    "tipo_dni": "DNI",
    "sexo": "F",
    "fecha_nacimiento": "2015-06-10"
  },
  "domicilio": {
    "calle": "Av. Ejemplo",
    "nro_calle": "5678",
    "provincia": "Salta",
    "departamento": "Capital",
    "localidad": "Salta"
  },
  "edad": 11,
  "tiene_cud": "NO",
  "tipo_cobertura": "PRIVADA",
  "nombre_cobertura": "OSDE"
}

Response — 200 OK

{
  "id": 1,
  "persona": { ... },
  "domicilio": { ... },
  "responsable": 1,
  "edad": 11,
  "tiene_cud": "NO",
  "tipo_cobertura": "PRIVADA",
  "nombre_cobertura": "OSDE",
  "responsable_detalle": { ... }
}

Ejemplo con curl (PATCH parcial)

curl -X PATCH http://localhost:8000/api/v1/1/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"edad": 11, "tipo_cobertura": "PRIVADA"}'

Parámetros de URL

ParámetroTipoDescripción
idintegerID del paciente a actualizar
