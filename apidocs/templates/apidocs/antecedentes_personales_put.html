Guardar antecedentes personales

PUT /api/v1/<id>/antecedentes-personales/ Requiere: Autenticación

Descripción

Crea o actualiza los antecedentes personales de un paciente (upsert). Si no existen, se crean con valores por defecto y luego se aplica la actualización parcial.

Request Body

{
  "nacio_prematuro": "NO",
  "peso_nacimiento": "3.200",
  "convulsiones_epilepsia": "NO",
  "mareos_desmayos": "NO",
  "asma_espasmos": "NO",
  "diabetes": "NO",
  "cardiopatia_congenita": "NO",
  "otras_enfermedades": "NINGUNO"
}

Response — 200 OK (actualizado) o 201 Created (nuevo)

{
  "nacio_prematuro": "NO",
  "peso_nacimiento": "3.200",
  "convulsiones_epilepsia": "NO",

  "tuberculosis": "NO",

Ejemplo con curl

  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"nacio_prematuro": "NO", "peso_nacimiento": "3.200"}'
